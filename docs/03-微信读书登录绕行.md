# 微信读书登录绕行（HTTP 401 问题）

## 问题

2026-10-22 起，微信读书服务端不再给 `/r/weread-skills` 下发会话 Cookie，导致插件扫码登录在轮询 `getLoginInfo` 时返回 **HTTP 401（-2013 鉴权失败）**：

```
扫码登录失败: plugins/weread.koplugin/weread/lib/qr_login.lua:114: getLoginInfo failed: HTTP 401
```

上游 issue：finlater/weread.koplugin#214（截至 2026-10-29 未修复）。插件本身工作正常，缺的只是"扫码建立会话"这一步。

## 绕行方案（已验证可用）

手动把「浏览器登录后的 Cookie」+「手机端 Skill API Key」写入 Kindle 的插件配置
`/mnt/us/koreader/settings/weread.lua`。

### 步骤

1. 手机微信读书 App → 我 → 设置 → 微信读书 Skill → 获取 API Key（`wrk-` 开头）。
2. Kindle：KOReader 工具 → SSH 启动服务。
3. 电脑运行：

```powershell
cd D:\coding\kindle\tools
.\Weread-Login.ps1
```

脚本会打开一个临时浏览器窗口，用微信扫码登录 `weread.qq.com` 后，自动：
- 通过 DevTools 协议读取 `wr_vid / wr_gid / wr_skey / wr_rt / wr_ql / wr_fp`；
- 下载 Kindle 上的 weread.lua，写入 api_key + cookies + user_vid；
- 推送回 Kindle 并校验。

4. Kindle 上退出 KOReader 再重新打开 → 工具 → 微信读书 → 书架。

### Cookie 过期后

在浏览器里重新扫码登录，再跑一次 `Weread-Login.ps1` 即可。

### 相关脚本

- `tools/Weread-Login.ps1` — 一键登录助手
- `tools/cdp_cookies.py` — 通过 DevTools 协议读 Cookie
- `tools/patch_weread_settings.py` — 写 weread.lua
- `tools/fix_weread_settings.py` — 配置写坏时从残留内容恢复

### 安全说明

Cookie 等于账号会话凭据，仅保存在你本机 Kindle 配置中。若想失效：退出微信读书网页登录，或删除 Kindle 上 weread.lua 中的 cookies 段。
